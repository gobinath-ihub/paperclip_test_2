# User Flows

## 1. Inquiry Flow (The Happy Path)
- **Land:** User arrives on `Home` page.
- **Browse:** User scrolls down, sees high-level services summary.
- **Intent:** User clicks "View All Services".
- **Selection:** User explores `Services` page, finds a relevant service.
- **Action:** User clicks "Get a Quote" or "Contact Us".
- **Conversion:** User fills out the form on the `Contact` page and submits.

## 2. Trust Building Flow (Portfolio)
- **Land:** User arrives on `Home` page.
- **Discovery:** User clicks on "Portfolio" in the navigation.
- **Validation:** User browses past projects, clicks on a specific project for details.
- **Interest:** User clicks "Start a project like this".
- **Conversion:** Redirected to `Contact` page with pre-filled interest (optional UX improvement).

## 3. Agency Background Flow
- **Land:** User arrives on `Home` page.
- **Curiosity:** User clicks "About Us".
- **Education:** User reads about the team, mission, and values.
- **Next Step:** User clicks on "Our Services" at the bottom of the About page.
- **Discovery:** User explores services.
