# NextGen Agency Design System (v0.1)

## Design Tokens

### Colors
| Token | Value | Description |
|-------|-------|-------------|
| `--color-primary` | `#007AFF` | Electric Blue - Primary actions |
| `--color-secondary` | `#5856D6` | Indigo - Secondary emphasis |
| `--color-background` | `#FFFFFF` | White - Primary background |
| `--color-bg-alt` | `#F2F2F7` | Light Gray - Alternate background |
| `--color-text` | `#1C1C1E` | Black - Primary text |
| `--color-text-muted` | `#3A3A3C` | Dark Gray - Secondary text |
| `--color-accent` | `#FF2D55` | Pink - Accents and highlights |

### Typography
| Token | Value | Description |
|-------|-------|-------------|
| `--font-family` | `Inter, -apple-system, sans-serif` | Main font family |
| `--text-h1` | `40px / 1.2 / Bold` | Page headers |
| `--text-h2` | `32px / 1.2 / Bold` | Section headers |
| `--text-h3` | `24px / 1.3 / SemiBold` | Sub-section headers |
| `--text-body` | `16px / 1.5 / Regular` | General content |
| `--text-small` | `14px / 1.4 / Regular` | Captions, metadata |

### Spacing (Base 8px)
| Token | Value |
|-------|-------|
| `--space-xs` | `4px` |
| `--space-sm` | `8px` |
| `--space-md` | `16px` |
| `--space-lg` | `24px` |
| `--space-xl` | `32px` |
| `--space-xxl` | `48px` |
| `--space-xxxl` | `64px` |

## Components (General Guidelines)

### Buttons
- **Primary:** `--color-primary` background, white text, 8px border-radius.
- **Secondary:** `--color-bg-alt` background, `--color-primary` text.

### Inputs
- Border: 1px solid `--color-bg-alt`.
- Padding: `--space-md`.
- Radius: 8px.
